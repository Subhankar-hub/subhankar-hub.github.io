Vim · Tmux · Terminal

Personal reference for this machine — shortcuts, plugins, LSP, and tmux integration. Vim 9.1 · tmux 3.6 · zsh. Leader is Space. tmux prefix is Ctrl-b.

How to read this. Keys in chips are chords you press. :Command is typed in Vim command mode (press : first). Leader means Space. Prefix means Ctrl-b in tmux. Custom maps from ~/.vimrc and ~/.tmux.conf are marked in the tables; everything else is stock Vim / zsh / tmux. Raw files: dotfiles page.

12. Vim ↔ tmux integration

The plugin christoomey/vim-tmux-navigator plus the matching block in ~/.tmux.conf make one navigation language for both programs.

You pressIf focus is a Vim splitIf focus is a tmux pane
Ctrl-hLeft Vim window, or into the tmux pane on the left at the edgeLeft tmux pane
Ctrl-jDown Vim window / out into tmuxDown tmux pane
Ctrl-kUp Vim window / out into tmuxUp tmux pane
Ctrl-lRight Vim window / out into tmuxRight tmux pane
Ctrl-\Previous Vim window / tmux panePrevious tmux pane
Typical layout: one tmux session per project. Window 1: Vim. Window 2: build/test shell. Or: left pane Vim, right pane compiler. Move with Ctrl-h/l as if they were the same editor. After editing ~/.tmux.conf, run Prefix r.

Clearing the screen: Ctrl-l no longer clears, because it moves panes. Use Prefix Ctrl-l or type clear.

14. Everyday workflows

  1. Start work: tmux new -s proj (or tmux a -t proj). Split with Prefix |. Left: vim . Right: shell.
  2. Open a file: Ctrl-p, type a fuzzy name, Enter. Or Ctrl-n and browse NERDTree.
  3. Search the repo: Space /, type a string, Enter on a hit.
  4. Jump around code: gd definition, gr references, K hover, Ctrl-o back.
  5. Fix diagnostics: ]d next error, Space d detail, Space ca code action. Save formats the buffer.
  6. Git: Space gs status, s to stage, cc to commit. Gutter: ]h next hunk, Space hs stage hunk.
  7. Leave: ZZ or Space w then Space q. Detach tmux with Prefix d.
